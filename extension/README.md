# Z’s Download Manager browser extension

For Chrome and Edge. Start the Z’s Download Manager desktop app on the same computer.

1. Extract the extension ZIP.
2. Open `chrome://extensions` or `edge://extensions`, enable **Developer mode**, and select **Load unpacked**.
3. Select the extracted folder containing `manifest.json`.
4. In the desktop app, open **Browser Extension** and copy the connection key.
5. Open the browser extension, paste the key, and click **Connect**.

Right-click an HTTP or HTTPS link and select **Send to Z’s Download Manager**, or paste the direct file link into the popup. The app marks the queued file **Sent from browser** and uses its default destination. The extension sends the link to the app and does not forward browser cookies.
